kanban-pro Public · AGPL-3.0

An augmenting proxy that gives coding agents one canonical, MCP-driven board over any kanban backend.

  • Anti-corruption layer (ports & adapters): front an existing kanban — a Jira board, a Hermes board — or use the native store, all behind one API, and mirror and move cards across boards to keep multiple kanbans in sync. It began as that proxy and grew into a complete standalone board.
  • Atomic claim/lease as a single-statement compare-and-swap — two agents never take the same card, and a crashed agent's lease expires so the card is redelivered.
  • Server-side workflow enforcement and agent-to-agent escalation, with structured "current-truth" work reports and an append-only change-feed making the board — not a transcript — the source of truth.

model-pro Coming soon

A self-hosted, OpenAI-compatible inference gateway fronting local and cloud backends on one GPU.

  • On-demand load with VRAM-aware eviction and a never-silently-substitute contract — typed errors, not surprise models.
  • Serves subscription-based Claude and GPT via their CLIs as backends — drive an existing Claude / ChatGPT plan through one OpenAI-compatible endpoint, alongside local and API models.
  • Virtual model groups: a name like "coder" or "agent" resolves down an ordered preference list of concrete backends with fallback — adopting an already-loaded model instead of forcing a churny reload.
  • An eval harness scores candidate models by replaying your own real sessions as independent rollouts — not imitation-grading — and even flags when a weak tool description, not the model, is at fault.
  • Usage & load statistics: a recorded history of load / evict events and requests across every backend.

kanban-dispatcher To be published

Turns a kanban-pro board into a running agent fleet.

  • Infers success structurally from board state — it never parses worker output.
  • Hardened for unattended runs: poison-card retry caps, quota-parking that reschedules without burning retries, and crash-safe redelivery inherited from the board's leases.
  • Wakes on the change-feed — pickup latency 30s → 2s.

Palisade Coming soon

A prompt-injection defense proxy you put in front of an LLM and its tools.

  • Screens every input — deobfuscate → deterministic score → block or escalate. It never certifies "safe": an LLM layer can raise suspicion but never clear it, so nothing talks its way to a pass.
  • Guards the output side (persona-drift, disclosure) and gates tool calls to what the persona is actually allowed to do.
  • Defenses are forged in a built adversarial arena: a self-hardening persona rewrites its own prompt until attack-success collapses, and a rule-miner turns winning attacks into deterministic detectors.
