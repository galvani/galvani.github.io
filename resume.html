Self-directed R&D — responsible end-to-end for designing, building, and open-sourcing the agent-orchestration, LLM tooling, and self-hosted-inference systems below.

kanban-pro (open source, AGPL) — an augmenting proxy giving coding agents one canonical, MCP-driven board over any kanban backend (front Jira/Hermes or use its own store; mirror and move cards across boards), with server-side workflow enforcement and an atomic claim/lease so two agents never take the same card and a crashed one's work is redelivered. Its companion kanban-dispatcher turns it into a self-hosted agent fleet — per-role agent profiles pull and work cards autonomously, with crash-safe redelivery and quota-parking.

model-pro — a self-hosted, OpenAI-compatible inference gateway putting local, cloud, and subscription-based backends behind one endpoint — including Claude and GPT via their CLIs, so an existing Claude/ChatGPT plan works as a backend, not just metered API keys. On-demand load with VRAM-aware eviction, virtual model groups with fallback, a never-silently-substitute contract, and usage statistics; its eval harness scores models by replaying my own real sessions as independent rollouts — not imitation-grading.

Palisade (in progress, open source) — a prompt-injection defense proxy for LLMs: a screen that deobfuscates and scores every input deterministically and blocks or escalates, never certifying "safe" (an LLM layer can raise suspicion but never clear it). Its defenses are forged in an adversarial arena with two self-improving loops — a self-hardening persona that rewrites its own prompt until attacks collapse, and a rule-miner that turns winning attacks into detectors.

world-around-me (self-hosted) — a local-first personal knowledge graph and applied-RAG track: a data-ingestion pipeline pulls ~38k messages into a graph store (SQLite + Neo4j) at ~100% schema-valid LLM extraction, and a closed-loop vocabulary controller feeds stabilized tags back into each extraction so the tag space converges instead of drifting. Hybrid graph-plus-vector retrieval works today; query router and retrieval eval are on the roadmap.
